# TrueSignal

**Creator-first networking for small and emerging creators.**

TrueSignal helps creators get discovered for their interests, skills, ideas, and creative potential — not just follower count.

Built for **RevenueCat Shipaton 2026**.

## The problem

Traditional social platforms often reward creators who already have reach. TrueSignal is designed around a different signal: what someone cares about, what they can create, and who they could create with.

## MVP

- Creator onboarding
- Interest and skill selection
- Interest DNA
- Interactive Interest Constellation
- Creator discovery
- Shared + complementary interest matching
- Transparent "Why you match" explanations
- Collaboration suggestions
- RevenueCat-powered TrueSignal Pro

## Stack

- React Native
- Expo
- TypeScript
- Expo Router
- Supabase
- RevenueCat

## Product loop

`Onboard → Build Interest DNA → Discover → Understand the match → Create together`

## Status

Early development. The initial mobile foundation is being built from scratch for Shipaton 2026.
